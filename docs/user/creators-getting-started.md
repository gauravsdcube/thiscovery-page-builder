# Getting started with Thiscovery Page Builder

This page is for people who create and publish pages. Administrators enable the module and permissions; you build the page, set who can see it, and share the public URL.

## Where pages live

- **Network (global) pages** — created at site level under **Administration → Thiscovery Page Builder**. Use these for public portals that should not belong to a single space.
- **Space pages** — created inside a space. Members of that space (and guests, if the page is public) are the usual audience.

You need **Create pages** / **Create global pages** to start a page, and **Manage pages** / **Manage global pages** to edit and delete.

## Collections, standalone pages, and folders

A **collection** is a top-level URL prefix, for example `/consultations`. Child pages nest under it: `/consultations/my-page`.

A **standalone** page is top-level on its own, for example `/about`.

A **folder** is admin organisation only. It groups collections and standalone pages in the page list. Nested folders are allowed. Folders do not change public URLs. Child pages stay with their collection — file the collection, not each child.

On the page list, the left sidebar is **Top-level pages** (unfiled standalone pages), then **Folders**, then unfiled **Collections**, then **Templates**. Open a folder to see its nested folders, collections, and pages. Add a child with **Add page** on a collection.

## Create a page

1. Open **Thiscovery Page Builder** (Administration, or the space menu).
2. Choose **New folder**, **Create collection**, **Create page**, or start from a saved **template**.
3. You land in the **studio** (or the folder form, for folders).

## The studio

The studio is the editor for one page. Tabs are:

| Tab | What you do there |
| --- | --- |
| Page builder | Add sections, choose layout, bind content |
| Settings | Title, slug, status, audience, space, menu, homepage, CSS, Share, Versions |

Open **Settings**, then pick a section in the left rail (same pattern as Forms).

**Preview** saves first, then opens the working draft. **Save page** stays in the editor. **Open page** is the live public link (the last **published edition**). **Publish current draft** on Share or Versions freezes the draft for visitors.

Changes are not live for visitors until you save **and** publish an edition (status must also be **Published**).
