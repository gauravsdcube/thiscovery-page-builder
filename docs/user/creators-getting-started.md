# Getting started with Thiscovery Page Builder

This page is for people who create and publish pages. Administrators enable the module and permissions; you build the page, set who can see it, and share the public URL.

## Where pages live

- **Network (global) pages** — created at site level under **Administration → Thiscovery Page Builder**. Use these for public portals that should not belong to a single space.
- **Space pages** — created inside a space. Members of that space (and guests, if the page is public) are the usual audience.

You need **Create pages** / **Create global pages** to start a page, and **Manage pages** / **Manage global pages** to edit and delete.

## Collections and standalone pages

A **collection** is a top-level URL prefix, for example `/consultations`. Child pages nest under it: `/consultations/my-page`.

A **standalone** page is top-level on its own, for example `/about`.

On the network list you can **Create collection** or **Create page**. Add a child with **Add page** on a collection.

## Create a page

1. Open **Thiscovery Page Builder** (Administration, or the space menu).
2. Choose **Create page**, **Create collection**, or start from a saved **template**.
3. You land in the **studio**.

## The studio

The studio is the editor for one page. Tabs are:

| Tab | What you do there |
| --- | --- |
| Page builder | Add sections, choose layout, bind content |
| Settings | Title, slug, status, audience, space, menu, homepage |
| Share | Public URL, preview, save as template |

**Preview** saves first, then opens the public page. **Save page** stays in the editor. **Open page** is the live public link (published pages).

Changes are not live until you save. Visitors only see **Published** pages (according to **Who can view**).
